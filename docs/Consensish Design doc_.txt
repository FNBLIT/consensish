2. During REVIEW PHASE, possible responses (POSITIONS) are
APPROVE [checkmark]
EXPRESS CONCERN [exclamation point]
ASK CLARIFYING QUESTION [question mark]
COMMENT [speachbox]
SUGGEST MODIFICATION [hammer]
STAND ASIDE [ghost]
BLOCK [X]
3. Every 3 DAYS, COHORT system groups 7 DECISION MAKERS into a COHORT
COHORT Grouping Heuristics
● Group VERY ACTIVE users with LESS ACTIVE users
● Group users that chose DIFFERING POSITIONS on previous 5
PROPOSALS
● Don’t group same users TWICE in a row
COHORT creates a group for each proposal for discussion,
in addition to the PROPOSAL DISCUSSION chat
